# Planner MCP Server

Intelligent task decomposition and planning using Ollama.

## Tools

- `decompose_task` - Break down complex tasks
- `create_implementation_plan` - Create detailed plans
- `estimate_task_complexity` - Estimate effort
- `identify_dependencies` - Find task dependencies
- `suggest_optimizations` - Optimize plans

## Requirements

Ollama with qwen2.5-coder:7b and gemma2:9b models.

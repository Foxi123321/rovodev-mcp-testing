# Rex Cognitive Framework for Website Intelligence

## 🧠 Overview

This framework enables Rex to understand websites as persistent, intelligent systems using 17 MCP servers across 5 phases:

1. **Phase 1: Mental Models** - Define schemas for website state and exploration goals
2. **Phase 2: Exploration Loop** - Multi-modal perception and adaptive learning
3. **Phase 3: Strategy Pivot** - Intelligent switching between UI and API strategies
4. **Phase 4: Integration Test** - End-to-end validation across real websites
5. **Phase 5: Validation & Persistence** - Store and retrieve learned patterns

## 📦 Project Structure


## 🚀 MCP Servers Used

### Knowledge & Memory (4 servers)
- `knowledge-database` - Store/retrieve patterns
- `deep-learning-v2` - Code analysis
- `sandbox-monitor` - Safe execution
- `filesystem-artifacts` - Artifact storage

### Browser & Testing (3 servers)
- `rex-unstoppable-browser` - Browser automation
- `testing-review-server` - UI testing
- `vision-server-simple` - Vision AI (llava)

### API & Integration (3 servers)
- `api-testing` - API recording/replay
- `gitops` - Version control
- `deployment` - Docker containers

### Planning & Validation (4 servers)
- `planner` - Task decomposition
- `plan-validator` - Plan validation
- `execution-auditor` - Verify execution
- `failure-classifier` - Error recovery

### Orchestration (3 servers)
- `rex-task-orchestrator` - Task management
- `atlassian` - Jira/Confluence integration
- `vision-server-simple` - Image analysis

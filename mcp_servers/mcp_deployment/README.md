# Deployment MCP Server

Docker and container management operations.

## Tools

- `docker_ps` - List containers
- `docker_build` - Build images
- `docker_run` - Run containers
- `docker_stop` - Stop containers
- `docker_logs` - Get logs
- `docker_compose_up` - Start services
- `docker_compose_down` - Stop services

## Requirements

Docker must be installed and running.
